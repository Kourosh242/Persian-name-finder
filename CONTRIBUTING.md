# Contributing

Thank you for contributing to Persian Name Finder.

📖 Full contributor guide (Persian): <https://github.com/Kourosh242/Persian-name-finder/wiki/Contributing>
📚 Adding a new name: <https://github.com/Kourosh242/Persian-name-finder/wiki/Name-Database>

## Steps

1. Fork the repository
2. Create a feature branch
3. Make your changes in `index.html` (the whole app lives in that single file)
4. Commit your changes
5. Open a Pull Request

## Notes

- Keep the app dependency-free and single-file — no npm/build step.
- Wiki pages are edited as markdown in `wiki/*.md`, then published with `./scripts/publish-wiki.sh`.

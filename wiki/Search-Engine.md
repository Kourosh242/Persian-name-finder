# 🔎 موتور جستجو | Search Engine

موتور جستجوی نسخهٔ ۲ کاملاً **سمت-کلاینت** است (بدون سرور) و از سه لایه تشکیل شده است:

```
ورودی کاربر
   │
   ▼
① normalize()            ← یکسان‌سازی حروف فارسی/عربی
   │
   ▼
② searchDB() / fuzzySuggest()   ← امتیازدهی ۶سطحی + Levenshtein
   │
   ▼
③ rootAnalysis()          ← تحلیل ریشه برای نام‌های ناشناخته
```

---

## ① نرمال‌سازی ورودی (`normalize`)

قبل از هر مقایسه‌ای، ورودی کاربر و نام‌های پایگاه با تابع `normalize` یکدست می‌شوند:

```js
function normalize(s){
  return String(s??"").toLowerCase()
    .replace(/ي/g,'ی').replace(/ك/g,'ک')   // ي عربی → ی فارسی، ك → ک
    .replace(/ة/g,'ه')                     // ة → ه
    .replace(/[أإآٱ]/g,'ا')                // همزه‌ها → ا
    .replace(/ؤ/g,'و').replace(/ئ/g,'ی')
    .replace(/[\u200c\u200f\u200e\u064b-\u065f\u0670]/g,'') // نیم‌فاصله + اعراب
    .replace(/\s+/g,' ').trim();           // فاصله‌های تکراری
}
```

نتیجه: «كوروش»، «کورُوش» و «کوروش» هر سه یکسان درک می‌شوند.

## ② جستجو و امتیازدهی (`searchDB`)

هر نام پایگاه با پرس‌وجوی کاربر مقایسه و **امتیاز ۰ تا ۱۰۰** می‌گیرد؛ ۶ سطح امتیاز وجود دارد:

| اولویت | شرط | امتیاز |
|:---:|:---|:---:|
| ۱ | تطابق کامل با نام یا املاهای جایگزین (`v`) | **۱۰۰** |
| ۲ | نام با پرس‌وجو **شروع می‌شود** (پیشوند) | `85 − min(10, len)` |
| ۳ | املاهای جایگزین با پرس‌وجو شروع شوند | **۷۰** |
| ۴ | نام **شامل** پرس‌وجو باشد | **۶۰** |
| ۵ | فاصلهٔ Levenshtein ≤ `⌊طول/۴⌋` (املا نادرست) | `45 − 10×فاصله` |
| ۶ | پرس‌وجو در **معنی** یا **توضیح** نام باشد | **۲۵** |

- نتایج بر اساس امتیاز نزولی و سپس ترتیب الفبایی فارسی (`fa` locale) مرتب می‌شوند و **۶ نتیجهٔ برتر** نمایش داده می‌شود.
- برای حالت «پیشنهاد زنده» تابع `fuzzySuggest` با فاصلهٔ حداکثر ۳، نزدیک‌ترین نام‌ها را پیشنهاد می‌کند.

## ③ فاصلهٔ Levenshtein (تحمل غلط املایی)

الگوریتم کلاسیک **فاصلهٔ ویرایشی** با پیچیدگی `O(m×n)` و مصرف حافظهٔ `O(n)` (فقط دو ردیف) پیاده‌سازی شده است:

```js
function lev(a,b){
  const m=a.length, n=b.length;
  if(!m) return n;  if(!n) return m;
  let prev = Array.from({length:n+1},(_,i)=>i);
  for(let i=1;i<=m;i++){
    const cur=[i];
    for(let j=1;j<=n;j++)
      cur[j]=Math.min(prev[j]+1, cur[j-1]+1,
                      prev[j-1]+(a[i-1]===b[j-1]?0:1));
    prev=cur;
  }
  return prev[n];
}
```

**مثال واقعی:** «کورش» ⟶ فاصلهٔ ۱ از «کوروش» ⟶ امتیاز ۳۵ ⟶ پیشنهاد می‌شود ✨

## ④ تحلیل ریشه (`rootAnalysis`)

اگر نامی در پایگاه نبود، خانوادهٔ زبانی آن با **قواعد هیوریستی** تخمین زده می‌شود:

| الگو | تشخیص |
|:---|:---|
| حروف لاتین | لاتین / اروپایی |
| داشتن «پ چ ژ گ» | فارسی |
| پیشوند «ال / عبد» یا حروف «ث ذ ص ض ط ظ ع غ ح» | عربی |
| پسوند «مهر فر زاد بانو دخت وند یار ناز دیس گین» | فارسی |
| پیشوند «مهـ آذر کی خو» | فارسی باستان |
| موارد دیگر | احتمالاً فارسی یا عربی |

## ⏱ بهینه‌سازی‌های تجربهٔ کاربری

- **Debounce:** پیشنهاد زنده با تأخیر ۱۰۰ms و فیلتر مودال با ۹۰ms — تا با هر تایپ، جستجو اجرا نشود.
- **پیمایش کیبورد:** ↑ ↓ برای حرکت بین پیشنهادها، Enter برای انتخاب، Esc برای بستن.
- **نرمال‌سازی یک‌بار برای هر نام** در هر جستجو (کارا روی آرایهٔ ۱۰۰تایی).

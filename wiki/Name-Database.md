# 📚 پایگاه دادهٔ نام‌ها | Name Database

پایگاه داده یک آرایهٔ جاوااسکریپت به نام `NAMES` است که در ابتدای `<script>` فایل `index.html` (ریشهٔ مخزن) تعریف شده و **۱۰۰ نام** را در بر می‌گیرد.

## ساختار رکورد

```js
{
  n: "کوروش",                    // نام (اجباری)
  v: ["کورش"],                   // املاهای جایگزین (اختیاری)
  p: "Kourosh",                  // آوانگاری لاتین (برای fallback ویکی‌پدیای انگلیسی)
  g: "پسر",                      // جنسیت: "پسر" | "دختر" | "مشترک"
  r: "فارسی باستان",             // ریشه / خاستگاه زبانی
  m: "خورشید؛ بنیان‌گذار شاهنشاهی هخامنشی",  // معنی
  d: "کوروش بزرگ بنیان‌گذار نخستین شاهنشاهی جهانی…", // توضیح بلندتر
  f: [                           // چهره‌های مشهور با این نام (اختیاری)
    "کوروش بزرگ (کوروش دوم هخامنشی)"
  ]
}
```

| فیلد | نوع | توضیح |
|:---:|:---:|:---|
| `n` | string | نام اصلی — یکتا |
| `v` | string[] | املاهای رایج جایگزین؛ در جستجو امتیاز کامل می‌گیرند |
| `p` | string | آوانگاری لاتین؛ برای جستجوی ویکی‌پدیای انگلیسی به‌کار می‌رود |
| `g` | enum | `"پسر"` 🌊 · `"دختر"` 🌸 · `"مشترک"` ✨ |
| `r` | string | ریشه: فارسی باستان، پهلوی، اوستایی، پارتی، فارسی، عربی، … |
| `m` | string | معنی کوتاه (قابل کپی با دکمهٔ 📋) |
| `d` | string | توضیح بلندتر: داستان، تاریخ یا ادبیات |
| `f` | string[] | چهره‌های مشهور؛ هر مورد به ویکی‌پدیای فارسی لینک می‌شود |

> 🔍 نام‌ها با قالب «`نام — توضیح`» نوشته می‌شوند؛ بخش قبل از «—» به‌طور خودکار برای لینک ویکی‌پدیا جدا می‌شود.

## ✅ راهنمای افزودن نام جدید

۱. فایل `index.html` ریشهٔ مخزن را باز کنید و آرایهٔ `NAMES` را پیدا کنید.
۲. رکورد جدیدی **به پایان آرایه** اضافه کنید (ترتیب فعلی: پسران، سپس مشترک‌ها، سپس دختران):

```js
{n:"بهنام",p:"Behnam",g:"پسر",r:"فارسی",m:"نام نیک، دارای نشان نیک",
 d:"نامی کهن به معنای کسی که نامش نیکوست.",
 f:["بهنام صفوی — خواننده"]},
```

۳. اگر املاهای رایج دیگری دارد، فیلد `v` را اضافه کنید: `v:["بهنام "]`
۴. شمارندهٔ بالای صفحه («📚 X نام در پایگاه محلی») خودکار به‌روز می‌شود.

### قواعد مشارکت

- رکورد را **کامل** پر کنید؛ حداقل `n`, `p`, `g`, `r`, `m`.
- معنی‌ها را از منابع معتبر نام‌های ایرانی بیاموزید و **ساده و محترمانه** بنویسید.
- برای `f` فقط افراد مشهور و قابل راستی‌آزمایی در ویکی‌پدیا را ذکر کنید.
- تنها سورس اپ `index.html` ریشه است؛ فایل `v2/index.html` فقط یک صفحهٔ ریدایرکت است و نباید تغییر کند.

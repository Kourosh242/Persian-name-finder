# 🇮🇷 فارسی

## معرفی

**Persian Name Finder** یک پروژه متن‌باز برای جستجوی نام‌های فارسی است که با تمرکز روی سرعت، تجربه کاربری و قابلیت نصب مانند اپلیکیشن موبایل طراحی شده است.

این پروژه به عنوان یک Progressive Web App ساخته شده و بدون نیاز به نصب از فروشگاه‌ها، روی موبایل و دسکتاپ قابل استفاده است.

- 🎨 رابط کاربری ساده و مدرن

## 🚀 اجرا

```bash
git clone https://github.com/MR-SHARIFI-Dev/persian-name-finder.git
cd persian-name-finder
```

سپس فایل `index.html` را اجرا کنید یا از یک سرور محلی استفاده کنید:

```bash
python -m http.server
```

# 🇬🇧 English

## About

**Persian Name Finder** is an open-source Progressive Web App for discovering and searching Persian names.

It is built with a focus on performance, accessibility, responsive design, and installable app experience.

## ✨ Features

- Fast Persian name search
- Persian RTL interface
- Progressive Web App support
- Offline caching
- Mobile installation support
- Lightweight and fast performance
- Modern responsive design

## 🚀 Installation

```bash
git clone https://github.com/MR-SHARIFI-Dev/persian-name-finder.git
cd persian-name-finder
```

Run locally:

```bash
python -m http.server
```
